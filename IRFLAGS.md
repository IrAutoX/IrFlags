# IrFlags

IrFlags is the Persian-localized BZFlag 2.4 client maintained by **DeathAmir And IrAutoX**.

This fork keeps the original BZFlag gameplay and upstream LGPL/MPL licensing while adding:

- Persian UI localization
- Persian RTL shaping in the legacy image-font renderer
- Vazirmatn-based Persian font atlases under SIL Open Font License 1.1
- IrFlags Windows branding and Persian-first launcher

Original BZFlag copyright and contributor attribution remain in the repository and release licensing files.
